# EVM Contracts Test Orchestration

Test orchestration for Atomica EVM contracts using the Docker testnet.

## Quick Start

```bash
# Install dependencies
bun install

# Start testnet and run all tests
bun run start

# Run specific test types
bun run test:unit      # Unit tests only
bun run test:integration  # Integration tests only
bun run test:e2e       # E2E tests only
bun run test:smoke     # Quick smoke test
```

## Architecture

```
┌─────────────────────────────────────────────────────────┐
│           Test Orchestrator (Bun + TypeScript)          │
│                                                         │
│  1. Starts Docker testnet via EthereumDockerTestnet    │
│  2. Deploys contracts via Forge                        │
│  3. Runs Foundry tests (unit/integration/e2e)          │
│  4. Collects and reports results                       │
│  5. Tears down testnet                                 │
└─────────────────────────────────────────────────────────┘
                           │
                           ▼
┌─────────────────────────────────────────────────────────┐
│         Docker Testnet (source/docker-testnet/)         │
│                                                         │
│  - Geth (execution layer)  :8545                        │
│  - Lighthouse (beacon)     :5052                        │
│  - Validator clients       :4                           │
└─────────────────────────────────────────────────────────┘
                           │
                           ▼
┌─────────────────────────────────────────────────────────┐
│              Foundry Tests (test/)                       │
│                                                         │
│  test/unit/        Pure unit tests                      │
│  test/integration/ Multi-contract integration tests     │
│  test/e2e/         Full Docker stack tests              │
└─────────────────────────────────────────────────────────┘
```

## Test Types

### Unit Tests (`test/unit/*.sol`)

Pure Solidity tests with no external dependencies:
- Math and logic verification
- Access control checks
- Event emissions
- State transitions

Run: `forge test --match-path test/unit/*.sol`

### Integration Tests (`test/integration/*.sol`)

Tests multi-contract interactions on forked testnet:
- Deposit → confirm → settle flow
- BLS key rotation
- Cross-contract calls

Run: `forge test --match-path test/integration/*.sol --fork-url $ETH_RPC_URL`

### E2E Tests (`test/e2e/*.sol`)

Full Docker stack tests:
- Real contract deployment
- Actual deposit transactions
- BLS signature verification
- State proof generation

Run: `forge test --match-path test/e2e/*.sol --rpc-url $ETH_RPC_URL`

## Environment Variables

| Variable | Description | Default |
|----------|-------------|---------|
| `ETH_RPC_URL` | RPC endpoint | `http://localhost:8545` |
| `ETH_PRIVATE_KEY` | Deployer private key | Anvil default key |
| `USDC_TOKEN_ADDRESS` | USDC token address | Required for deployment |
| `FOUNDRY_PROFILE` | Foundry profile | `test` |

## Development

```bash
# Start only the testnet
bun run test-orchestration/src/index.ts --test smoke --keep-alive

# In another terminal, run tests manually
export ETH_RPC_URL="http://localhost:8545"
forge test --match-path test/e2e/*.sol

# Clean up
bun run test-orchestration/src/clean.ts
```

## CI Integration

```yaml
# .github/workflows/test.yml
name: Tests

on: [push, pull_request]

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - name: Install Bun
        uses: oven-sh/setup-bun@v1

      - name: Install Foundry
        uses: foundry-rs/foundry-toolchain@v1

      - name: Run tests
        run: |
          cd source/evm-contracts
          bun install
          bun run ../test-orchestration/src/index.ts --test all
```

## Troubleshooting

### Testnet won't start

```bash
# Check Docker is running
docker ps

# Check for port conflicts
lsof -i :8545 -i :5052

# Manual cleanup
cd source/docker-testnet/ethereum-testnet/config
docker compose down -v
```

### Deployment fails

```bash
# Ensure USDC_TOKEN_ADDRESS is set
export USDC_TOKEN_ADDRESS="0x..."

# Check RPC connectivity
curl -X POST http://localhost:8545 \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","method":"eth_blockNumber","params":[],"id":1}'
```

### Tests timeout

```bash
# Increase timeout in test-orchestration/src/index.ts
await testnet.waitForHealthy(300);  // 5 minutes
```
